# Kingdom Rush 中途存档 v9（实验版）

这是为 **初代 Steam 版 Kingdom Rush（AppID 246420）**做的 Windows 原型。它在游戏内添加两个按键：

- **F5**：可以在波次进行中保存资源、波次、已建塔位，以及可识别的怪物、英雄和兵营士兵状态。提示会显示各类单位记录数；一座塔都无法记录时，F5 会保留上一个检查点而不覆盖。
- **F9**：进入同一关卡、相同模式和难度且尚未出兵时，在 5 秒内按两次恢复。塔会逐座、逐级通过游戏原生建造流程恢复；之后恢复英雄与兵营士兵，再重建怪物并核验，最后才显示成功。
- **v9**：F5 记录游戏实际准备出击的下一波编号；F9 将原生刷怪协程定位到这一波，并刷新提前出怪旗标。已恢复的敌人保留在场上，不会再从第一波开局。
- 技能仍通过游戏原生按钮接口解锁；F5 记录火雨和增援的剩余冷却，F9 按保存时的冷却状态恢复。

初代游戏原生的 `slot_*.lua` 保存的是关卡间的玩家进度，不含当前战场。中途检查点单独写入：

```text
%APPDATA%\kingdom_rush\kr_midlevel_checkpoint.json
```

## 使用

1. 安装 Python 3.10 或更新版本（需要包含 Tkinter）。
2. 完全退出游戏，双击本目录中的“启动工具.bat”打开管理器。
3. 如果已安装旧版补丁，先点“恢复原版游戏文件”，从 Steam 打开游戏确认地图正常，再退出游戏。
4. 选择初代 Steam 游戏目录里的 `Kingdom Rush.exe`，点“安装实验补丁”安装 v9。若之前已安装补丁，先点“恢复原版游戏文件”，再安装新版。
5. v2–v8 检查点仍可读取；旧检查点没有单独记录下一波编号，v9 会根据存档波数推算。之后按 F5 保存的新检查点会明确记录下一波。F5 会保留上一份检查点为 `.previous`，避免新保存失败时丢失旧文件。
6. 之后从主菜单进入保存时的同一关卡、模式和难度；在尚未出兵时，5 秒内按两次 **F9**。请等屏幕明确显示 `Checkpoint restored: ...`。
7. 要卸载时，完全退出游戏后点“恢复原版游戏文件”。

安装时，程序会先把原版 exe 以带时间戳的文件名保存在游戏目录。补丁只写入游戏 exe 资源包和独立的检查点文件；普通存档仍在原目录。也可以用界面里的按钮备份普通存档。

## 状态和限制

旧版曾直接覆盖游戏运行时状态对象，可能导致塔失去攻击能力和地图异常。v2 不再序列化地图或模拟器对象，但恢复时并发触发塔建造且等待时间过短；v3 改为逐座、逐级恢复并核对塔位。v4 还会从 `tower.holder_id` 或 `ui.nav_mesh_id` 读取塔位编号，并分别报告缺少编号和不支持的塔型。v5 通过现存实体的字段快照与游戏原生的塔、兵营及模拟器接口恢复战场单位。v6 加入技能按钮快照。v7 直接改按钮字段，游戏界面仍可能把技能显示为未解锁。v8 改为调用游戏原生按钮状态接口。v9 读取并调整游戏原生刷怪协程的等待波次，同时刷新游戏界面的下一波旗标；不使用虚空波，也不调用出兵命令。

v5 会恢复资源、生命、波次计数和四类标准塔及其常规升级路线；怪物记录血量、位置和路径进度，英雄记录血量、等级、经验、技能表中的可识别字段、位置和集结点，兵营士兵记录血量、等级，兵营恢复集结点。英雄必须与保存时相同；士兵由兵营原生生成后再套用快照。v9 会恢复下一波序号和提前出怪旗标，但不会保存当前波次尚未刷出的敌人队列：如果在波次刷怪过程中存档，F9 会恢复已出场的敌人，并将下一次出击定位到后续波次，未刷出的部分不会补出。因此波间存档最稳妥。阵亡士兵的重生计时、怪物/英雄临时增益时长、塔和单位攻击目标与冷却、动画、投射物也不会精确续播；火雨与增援的按钮冷却由 v8 起单独记录。部分战斗行为会从新状态继续。缺少有效路径数据的怪物会跳过并在提示中说明。无法识别或缺少塔位编号的塔会在 F5 提示并跳过；F9 会在报告成功前核对已记录的塔位和怪物实体。

v2–v4 检查点不含战场单位数据；v5 检查点不含技能按钮状态；v6–v7 只记录技能是否处于冷却，不含剩余秒数。v8 起的检查点会记录技能准确冷却剩余时间。v9 接受 v2–v8 检查点；旧文件的下一波会按记录波数推算，旧文件也无法复原冷却剩余秒数。v1 和更早格式不兼容。恢复前必须手动进入保存时的同一关卡、模式和难度，在新局第一波尚未出兵时按两次 F9。第一次请先在不重要的关卡试用。不同游戏更新可能改变 Lua 状态结构，更新后要重新应用补丁。

如果 F9 结束后提示恢复未完成，请不要继续出兵；按提示确认对应塔位状态，再返回主菜单重新进入关卡。工具不会在恢复失败后推进到保存的波次。
